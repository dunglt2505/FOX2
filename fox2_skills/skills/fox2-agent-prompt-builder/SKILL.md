# Draft a useful FOX2 handoff

- Extract the intended result, actual task stage, allowed paths, completed work, tests and STOP conditions. Preserve the user's Agent/model choices and existing grants.
- Use a supplied template when available; if its authority is conditional, label the output a draft and retain that provenance. Do not invent a current official template.
- Write one self-contained prompt with measurable acceptance, evidence to return and excluded completed effects. Resolve missing non-material details by stating assumptions.
- For an executable assignment, apply the project's routing precheck and verify the material governing sources. Hold dispatch or ungranted rights while still delivering the draft.
- Return the handoff text and a short list of unresolved material bindings. Do not dispatch it.

Read [scope and source guidance](../../shared/host_guidance.md) when authority, canonical sources, task state or effects matter.
