# Save and verify documents within the actual publication grant

- Identify the document, revision/lineage, destination and exact requested action. Separate preparing a draft, saving bytes, publishing a release, updating Registry and mirroring.
- For a draft or expressly authorized local save, check destination existence and compare exact bytes. Preserve same-name different-byte content unless the user explicitly authorizes replacing it.
- Save only within the granted scope and read the destination back. Report save, release, Registry and mirror statuses separately; a local SAVE is not RELEASED_EFFECTIVE.
- If release authority is missing, still prepare the draft or save allowed bytes. Hold only release/promotion or other actions outside the actual grant.

Read [scope and source guidance](../../shared/host_guidance.md) when authority, canonical sources, task state or effects matter.
