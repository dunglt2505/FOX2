# Review claims against independently available evidence

- List the material claims and their acceptance criteria, then inspect the actual artifacts, tests, destination readback and observed behavior available to this review.
- Distinguish source integrity, metadata, helper tests, host invocation, substantive behavior and release acceptance. Never silently promote one layer to another.
- Identify concrete discrepancies with impact and evidence. Preserve uncertainty when an artifact cannot be read or a claimed test was not run.
- Deliver a technical review under the supplied provenance even if release authority is unverified. Hold only the governance-dependent acceptance decision; do not suppress actionable findings.

Read [scope and source guidance](../../shared/host_guidance.md) when authority, canonical sources, task state or effects matter.
