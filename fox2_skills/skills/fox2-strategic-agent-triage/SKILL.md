# Turn observed findings into one justified next decision

- Read the supplied findings and separate observations from hypotheses. Group related symptoms by supported root cause rather than opening a separate work package per symptom.
- Compare the concrete available options by acceptance impact, dependencies, risk and cost. Keep unknown causes explicit.
- Recommend the smallest coherent next action supported by the evidence. Explain what observation would change that recommendation.
- Deliver the analysis even if source release authority is unresolved; qualify any governance-dependent decision and withhold actual assignment, dispatch or release.

Read [scope and source guidance](../../shared/host_guidance.md) when authority, canonical sources, task state or effects matter.
