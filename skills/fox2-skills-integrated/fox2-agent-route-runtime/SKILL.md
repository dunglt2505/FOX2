# fox2-agent-route-runtime

## Activate when
The remaining work requires an execution owner/model choice or a route changes materially.

## Work to perform
Assess **residual** complexity, ambiguity, tool access, observed capabilities/quota, dependency risk and irreversible operations. Prefer direct CHAT execution when tools suffice. For coding requiring host access select native CODEX/Copilot or Bridge when that installed transport adds necessary execution capability. WORK is reserved for genuinely independent judgment, not routine coding or report routing.

Select one tuple `Actor · Model/Engine · Thinking · Execution transport · Scope · STOP` with least adequate cost and sufficient safety. Do not make High the default. If model/effort capability is UNKNOWN, say UNKNOWN rather than silently substitute. Preserve pinned task route and consumed attempt identity. Hand selected route to Prompt Builder; host/Bridge separately validates actual model and runtime permissions. No duplicate `TASK_ROUTE_ASSESSMENT` document for ordinary work.

## Completion / stop
One justified route in the existing task, with remaining required capability or blocker. No Agent execution claimed.

## Responsibility boundary
Own **selection, not permissions/PreExec, task prioritization, prompt composition or host launch**. `strategic-agent-triage` sets priority; Bridge enforces its actual route.

## Shared operating and Bridge applicability
FOX2 Agile Lite: one logical task, Build → Test → Deliver, CHAT owns outcome. Use only relevant methods and real evidence. Ordinary native DEV has no mandatory R0–R7/PreExec/Dispatch/extra approval; if the selected real route is Bridge or high-risk, its installed technical controls remain authoritative. No unrelated version churn, protected operations or consumed-attempt replay. This Skill does not authorize execution or grant external rights.
