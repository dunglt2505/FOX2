# fox2-document-publication

## Activate when

## Work to perform
First distinguish: ordinary native coding prompt (no required Git-first publication), Bridge-controlled technical task/prompt (Git transport proof needed), or actually governed documentation release (Git/Library authority proof).

For Bridge: write `task.md` and exact UTF-8 `prompt.md` to authorized non-main Git, read back exact commit/blob/hash, inspect public repo sensitive content, bind immutable source and correct allowed paths; do not call Git push Agent execution. For governed Policy/BRD/TechSpec: verify Owner scope, destination comparison, commit/file/hash, required Library byte readback, and only then separately authorized current pointer update. Preserve differing destination WIP; publication is not machine runtime adoption, and no bulk version bumps.

Record only real state: DRAFT/SOURCE_PUBLISHED/LIBRARY_VERIFIED/HUMAN_EFFECTIVE/MACHINE_ADOPTED as independently supported, not an invented all-PASS release. Do not publish an executable Bridge Dispatch merely to finish documentation release; require actual host evidence and installed Schema v3 validation.

## Completion / stop
Produce the concrete deliverable and actual proof with DONE/REWORK/BLOCKED or a precisely named lower execution state. Do not mark completed because a prompt, Dispatch, tool invocation or plan exists. CHAT owns the end-to-end result.
