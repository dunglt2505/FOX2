# fox2-document-publication

## Activate when
Owner requests creation, update or release of an actual governed document.

## Work to perform
Determine approved source, type, destination, version scope and independent evidence of authority. Compare actual Git bytes/commit and Library destination before authorized write, preserve conflicting WIP, perform required readback, and distinguish draft, published, current/effective, and installed machine adoption. Avoid cascading version edits. Prompt/task transport files for actual Bridge are **technical transport artifacts** managed by the selected Bridge/Git publisher, not governed Policy release; native prompts do not automatically require Git publication.

## Completion / stop
Exact published path/version/hash and honest scoped status, or one real blocked destination/authority.

## Responsibility boundary
Own **governed-document lifecycle**, not Git task/prompt transport for Agent execution, generic source copying or Bridge Dispatch.

## Shared operating and Bridge applicability
FOX2 Agile Lite: one logical task, Build → Test → Deliver, CHAT owns outcome. Use only relevant methods and real evidence. Ordinary native DEV has no mandatory R0–R7/PreExec/Dispatch/extra approval; if the selected real route is Bridge or high-risk, its installed technical controls remain authoritative. No unrelated version churn, protected operations or consumed-attempt replay. This Skill does not authorize execution or grant external rights.
