# fox2-governance-preflight

## Activate when
A selected route requires technical authorization, PreExec, source identity, host or no-replay proof.

## Work to perform
Classify normal independent native DEV versus actual Bridge/irreversible execution. Normal DEV verifies task scope, writer, rights and proportionate tests, not a durable PreExec receipt or R0–R7 worksheet.

For actual Bridge: verify installed machine Dictionary/Schema/Policy/source lock; exact task and prompt commit/hash; remote task branch and worktree ownership; no conflicting writer/unrelated dirty state; configured CLI and supported actor/model/effort; real authority/permissions and protected-operation deny values; ledger attempt not consumed; concrete route-dependent PreExec status. Validate against installed preflight receipt schema and actual receipt path. Never set `decision_receipt` flags to PASS on assumption. `policy_check`, `task_state_check`, `source_binding_check`, `routing_r0_r7`, `assignment_check` and material capability must come from observed route checks; `dev_grant_ref` must be actually evidenced.

Only release an executable Dispatch candidate when every required material check is observed and its v3 validation succeeds. STOP the affected action on `BLOCKED`, `UNKNOWN`, `NOT_RUN`, `INFRA_FAILED`, mismatched source, missing permission, conflicting worktree, or already consumed attempt; continue unrelated safe tasks. Don't count PreExec as Agent run or result acceptance. A scoped Owner management waiver is not technical PASS or provider rights.

## Completion / stop
Produce the concrete deliverable and actual proof with DONE/REWORK/BLOCKED or a precisely named lower execution state. Do not mark completed because a prompt, Dispatch, tool invocation or plan exists. CHAT owns the end-to-end result.

## Shared operating and Bridge applicability
Apply shared `../../shared/operating_rules.md`. A routine reversible independent native task needs no Bridge Dispatch, manual R0–R7 artifact or immutable prompt publication. When and only when the actual execution is Bridge-controlled, follow `../../shared/bridge_e2e_v041.md` and the **installed** runtime contract, not an assumed current version. All source/receipt/test evidence must be observed, not invented. Old consumed attempts remain immutable and non-replayable. Complete outcomes in the SAME logical task; do not create administrative micro-WPs.
