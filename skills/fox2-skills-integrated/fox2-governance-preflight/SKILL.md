# fox2-governance-preflight

## Activate when
A selected execution or publication action requires a safety, authorization or host readiness check.

## Work to perform
Classify the **specific action**: ordinary reversible internal change, governed source publication, actual Bridge execution or high-consequence operation. For ordinary native DEV, check sufficient writer/path permission, independent tests and authorized task scope; do not demand a formal receipt.

For actual Bridge, inform the host/Bridge validator what must be observed: installed machine Dictionary/Schema and source contract, exact authorized source/task, agent capability/model, route, worktree ownership, writer, permission grant, PreExec and unused-attempt ledger. **The Bridge implementation executes and validates these checks**; do not generate PASS values, manufacture receipts, create Dispatch or perform host installation from Skill prose.

Reject unproven authority, mismatch, unknown material capability and no-replay violations for the affected action only. A historical Policy version in a pinned Bridge machine contract is not by itself source conflict.

## Completion / stop
Concise `PROCEED`/`BLOCKED`/`UNKNOWN` decision for the particular action, grounded in real checks; separate observed machine result from advisory preparation.

## Responsibility boundary
Own **applicability and interpretation of safeguards**. Installed Bridge PreExec/validator performs and records technical admission; Router selects Actor; Prompt Builder writes only prompt.

## Shared operating and Bridge applicability
FOX2 Agile Lite: one logical task, Build → Test → Deliver, CHAT owns outcome. Use only relevant methods and real evidence. Ordinary native DEV has no mandatory R0–R7/PreExec/Dispatch/extra approval; if the selected real route is Bridge or high-risk, its installed technical controls remain authoritative. No unrelated version churn, protected operations or consumed-attempt replay. This Skill does not authorize execution or grant external rights.
