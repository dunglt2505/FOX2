# fox2-source-resolver

## Activate when
A question concerns source authority, current policy, version compatibility or immutable reference.

## Work to perform
Use current authorized Governance Registry and dated Owner scope for new CHAT work (Policy v2.1.0, Routing v1.5.0 and Protocol v13 until valid supersession). Compare Git path, immutable commit/content, published status and provenance before claiming effectivity.

For an actual Bridge route, read its **installed** machine Dictionary and pinned schema/policy/source identity separately. Older Policy 1.8.9 and Dictionary 1.2 can remain valid Bridge machine bindings; do not overwrite them with the newer CHAT human-management Policy. Preserve consumed Dispatch locks. Differentiate `SOURCE_BYTES_VERIFIED`, `AUTHORITY_VERIFIED`, `HUMAN_EFFECTIVE`, `MACHINE_ADOPTED` and `RUNTIME_ENFORCED`. Unknown independent authority is `AUTHORITY_UNVERIFIED`, not proven `SOURCE_CONFLICT`.

## Completion / stop
One selected source set and scoped authority verdict, or exact source ambiguity without artificial reversion.

## Responsibility boundary
Own **source decision**, not copying/publishing bytes, upgrading consumers, preflight execution or authorizing the Agent.

## Shared operating and Bridge applicability
FOX2 Agile Lite: one logical task, Build → Test → Deliver, CHAT owns outcome. Use only relevant methods and real evidence. Ordinary native DEV has no mandatory R0–R7/PreExec/Dispatch/extra approval; if the selected real route is Bridge or high-risk, its installed technical controls remain authoritative. No unrelated version churn, protected operations or consumed-attempt replay. This Skill does not authorize execution or grant external rights.
