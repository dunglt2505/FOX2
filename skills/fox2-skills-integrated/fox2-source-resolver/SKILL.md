# fox2-source-resolver

## Activate when
Policy, source, Dictionary, BRD/TechSpec or Bridge binding may affect a new or changed task.

## Work to perform
Resolve projectwide human management from `docs/governance/FOX2_PROJECTWIDE_GOVERNANCE_REGISTRY.json` on actual authorized main: Policy 2.1.0, Routing Index 1.5.0, Task/Result Protocol v13 for new/re-scoped work. Verify authority and source bytes; latest filename alone is not controlling.

For Bridge route, separately read installed generated Dictionary's `SOURCE_COMMIT`, `SOURCE_SHA256`, `CURRENT['policy']`, `CURRENT_DISPATCH_SCHEMA`, control branch and path patterns. That machine may require historical Policy 1.8.9 and Dictionary 1.2. Bind those exact observed machine identity fields to v3 Dispatch; do not substitute human Policy 2.1.0. Historical Dispatch locks stay unchanged. If active machine and a required new action cannot coexist, report scoped `MACHINE_CONSUMER_INCOMPATIBLE` and identify the consumer/generator/test to change; do not rewrite BRDs or immutable past attempts.

Distinguish `SOURCE_BYTES_VERIFIED`, `AUTHORITY_VERIFIED`, `HUMAN_POLICY_EFFECTIVE`, `MACHINE_ADOPTED`, `RUNTIME_ENFORCED`. Missing trusted authority -> `AUTHORITY_UNVERIFIED`, not `SOURCE_CONFLICT` unless two proven competing authorities. Persist source commit/hash only where technical execution needs immutable identity; work directly on ordinary reversible tasks.

## Completion / stop
Produce the concrete deliverable and actual proof with DONE/REWORK/BLOCKED or a precisely named lower execution state. Do not mark completed because a prompt, Dispatch, tool invocation or plan exists. CHAT owns the end-to-end result.

## Shared operating and Bridge applicability
Apply shared `../../shared/operating_rules.md`. A routine reversible independent native task needs no Bridge Dispatch, manual R0–R7 artifact or immutable prompt publication. When and only when the actual execution is Bridge-controlled, follow `../../shared/bridge_e2e_v041.md` and the **installed** runtime contract, not an assumed current version. All source/receipt/test evidence must be observed, not invented. Old consumed attempts remain immutable and non-replayable. Complete outcomes in the SAME logical task; do not create administrative micro-WPs.
