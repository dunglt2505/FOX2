# FOX2 — Shared Agile Lite Skill Operating Guidance

**Source:** Policy v2.1.0; 2026-10-22 standing Owner management decision.  
**Status:** v0.4.0 SOURCE CANDIDATE, NOT INSTALLED.

- Skills are methods for doing the work, **not gates**, certificates or an extra approval chain. Activate only expertise relevant to the real task; unavailable unrelated Skills do not block ordinary work.
- One Kanban task, one objective, one outcome. CHAT acts directly where capable, assigns one bounded Agent only if needed, reviews material diff/test/output, and closes DONE / REWORK / BLOCKED.
- No automatic R0-R7 worksheet, separate Git task/prompt publication, PreExec receipt, Dispatcher lifecycle or secondary WORK audit for reversible, independent native DEV. If a real chosen runtime requires these technical contracts, retain them for that runtime only.
- Version hygiene: historical references/pinned receipts stay; do not cascade version bumps or reopen BRDs. Fix only an active source decision or machine consumer proven wrong.
- Keep actual authorization, one-writer scope, secret safety, relevant tests, protected branch controls and no-replay for consumed/irreversible effects. Never relabel unrun tests PASS or repeat a consumed dispatch.
- Owner approval of this reform covers ordinary internal management work. It never grants external broker/provider/LIVE, production, destructive or protected-main actions.
- Evaluate quality by working features and defects; preserve verified PASS where unchanged; only recheck invalidated evidence and safety-critical material controls.
