# fox2-method-source-contracts

**FOX2 Layer 2 — Domain methods — Agile Lite 0.5.0**

## Activate when
A task needs source version authority, change lineage, Dictionary field/schema impact or machine compatibility.

## Input
Current authorized Registry/Owner scope, Git identity, source/Dictionary schema and actually affected consumers.

## Work to perform
1. Resolve source by actual scoped Owner approval, Governance Registry, publication evidence and supersession; do not select highest filename version. For new CHAT work, Policy 2.1.0/Routing 1.5.0/Protocol 13 apply unless validly superseded.
2. If execution uses Bridge, independently inspect **installed** Dictionary, normalizer, schema and machine-pinned Policy. A historical machine Policy 1.8.9 may coexist with human Policy 2.1.0. Never stamp a new human Policy into an old executable Dispatch or rewrite consumed pins.
3. For semantic Dictionary changes, trace field name/ID/type/units/null vs zero/as-of time through only affected producers, consumers, generators and tests. Label unknown consumers; do not blindly rebind BRD/TechSpec versions.
4. Keep distinct claims: `SOURCE_BYTES_VERIFIED`, `AUTHORITY_VERIFIED`, `HUMAN_EFFECTIVE`, `MACHINE_ADOPTED`, `RUNTIME_ENFORCED`. Missing independent authority is UNKNOWN; competing source claims are CONFLICT only when evidenced.
5. Return the smallest consumer fix or a precise source compatibility HOLD; implementation/publishing is separate.

## Output
One authoritative source-set verdict plus affected consumer/compatibility map when relevant.

## Responsibility boundary
Owns source interpretation and schema impact. Does NOT publish sources, build Dispatch, run PreExec or change machine authority without a real release.

## Common rules
One logical Kanban task; only material checks for selected action. Ordinary native DEV has no mandatory Bridge/PreExec/R0–R7 paperwork. For actual Bridge execution the installed Bridge enforces its own machine protocol and no-replay; never fabricate PASS, permissions or host actions. CHAT owns result acceptance; no broker/LIVE, protected branch or irreversible side effects without real authority.
